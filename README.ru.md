# LAN Vault Bridge

Двусторонняя синхронизация хранилища Obsidian между ПК и телефоном по локальной
сети. Без облака, аккаунта и посредников: ПК поднимает сервер, телефон подключается
к нему напрямую. Удаления защищены tombstone-записями, конфликты разрешаются в
интерактивном окне.

> Плагин не связан с Obsidian. Это независимый community-плагин.

[English README](README.md)

## Возможности

- **Двусторонняя синхронизация по LAN.** Новые, изменённые и удалённые файлы
  передаются в обе стороны.
- **Без облака.** Никаких сторонних серверов, аналитики и телеметрии. Данные идут
  только между сопряжёнными устройствами в вашей сети.
- **Защита от удаления.** Удалённый файл не исчезает из манифеста, а получает
  статус `deleted_tombstone`. Случайное удаление не «воскрешает» старую версию и
  не стирает данные на другой стороне молча.
- **Разрешение конфликтов.** Если файл изменён с двух сторон или удалён на одной
  и изменён на другой, открывается окно с превью, построчным diff и действиями
  для каждого файла.
- **Сравнение по SHA-256.** Хеши считаются через Web Crypto API одинаково в
  Electron и Android/iOS WebView.
- **Сопряжение по QR.** ПК показывает QR-код с IP, портом и токеном; телефон
  импортирует тот же JSON из буфера обмена.
- **Двуязычный интерфейс.** Русский и английский, по умолчанию — язык Obsidian.
- **Мобильная архитектура.** Node-модули загружаются лениво только на ПК; телефон
  не использует Node-модули `http`, `os`, `fs`, `crypto`.

## Как это работает

1. ПК запускает HTTP-сервер на `0.0.0.0:27123` (порт можно изменить).
2. Телефон отправляет `GET /api/ping` и `POST /api/sync/diff` со своим манифестом.
3. ПК сверяет свой vault, сравнивает манифесты и возвращает `fileConflicts` и
   `contentDiffs`.
4. Если расхождений нет, плагин пишет «Хранилища идентичны: изменений не найдено».
5. Иначе открывается окно разрешения конфликтов: отправить, скачать, удалить или
   пропустить каждый файл. Карточка отмечается выполненной, счётчик уменьшается.

Манифест хранится в `.obsidian/plugins/lan-vault-bridge/sync-manifest.json`. Это
данные плагина, а не заметка, поэтому Obsidian их не индексирует.

## Требования

- Obsidian 1.5.0 или новее.
- ПК и телефон в одной локальной сети либо в одном VPN (Tailscale, ZeroTier).
- Windows, macOS или Linux для серверной стороны.
- Android или iOS для клиента; ПК тоже может быть клиентом.

## Установка

### Из каталога community

После публикации: **Настройки → Сторонние плагины → Обзор → найти «LAN Vault
Bridge» → Установить → Включить**.

### Вручную

Скачайте `main.js`, `manifest.json` и `styles.css` из последнего GitHub Release и
положите в:

```text
<vault>/.obsidian/plugins/lan-vault-bridge/
```

Перезапустите Obsidian и включите плагин в «Сторонних плагинах».

### На телефон

В мобильном Obsidian нет кнопки «установить плагин из файла». Скопируйте три файла
в скрытую папку `.obsidian/plugins/lan-vault-bridge/` через файловый менеджер,
который показывает скрытые файлы:

- **Android:** `Documents/Obsidian/<vault>/.obsidian/plugins/`; если vault лежит в
  `Android/data`, используйте ZArchiver или MiXplorer.
- **iOS:** Files → «На моём iPhone» → Obsidian → `<vault>`; если `.obsidian` не
  видна, используйте Documents by Readdle, Finder (File Sharing) или iMazing.

Готовые файлы — в
[последнем GitHub Release](https://github.com/hardkor88/lan-vault-bridge/releases/latest).

> Через сам LAN Vault Bridge установить плагин нельзя: всё внутри `.obsidian`
> игнорируется, иначе плагины синхронизировали бы сами себя.

## Сопряжение

1. На ПК откройте **Настройки → LAN Vault Bridge**.
2. Выберите локальный IPv4-адрес (в списке Wi-Fi, Ethernet, Tailscale, ZeroTier).
3. Отсканируйте QR-код телефоном или нажмите **«Скопировать строку подключения
   (JSON)»**.
4. На телефоне: **Настройки → LAN Vault Bridge → Быстрый импорт**, вставьте JSON и
   нажмите **«Импортировать»**.
5. Нажмите **«Проверить соединение»**. При успехе появится имя ПК и версия плагина.

Строка подключения выглядит так:

```json
{"ip":"192.168.1.5","port":27123,"token":"0123456789abcdef0123456789abcdef"}
```

## Синхронизация

- Нажмите иконку `refresh-cw`, выполните команду **«LAN Vault Bridge: Sync now»**
  или кнопку в настройках.
- Клиент сканирует vault, сравнивает хеши и отправляет манифест на ПК.
- В окне две секции:
  - **«Наличие файлов»** — только на телефоне, только на ПК, удалён на одной
    стороне или изменён после удаления.
  - **«Изменения в тексте и файлах»** — active на обеих сторонах, но SHA-256
    различается.
- Действия для файла: отправить на ПК, скачать на телефон, восстановить, удалить
  везде, принять версию с ПК, пропустить.
- Массовые действия:
  - **«Применить выбранное по умолчанию ко всем»** — сохраняет данные: новые файлы
    копируются, удалённые предлагается восстановить, побеждает более свежая версия.
  - **«Принять все с ПК»** — телефон приводится к состоянию ПК.
  - **«Отправить все на ПК»** — ПК приводится к состоянию телефона; файлы, которых
    нет на телефоне, будут удалены на ПК (с подтверждением).

## Безопасность и приватность

- **Никаких сторонних серверов.** Плагин общается только с сопряжённым ПК по
  локальной сети. Ничего не отправляется автору или в аналитику.
- **Bearer-токен.** Все запросы, кроме `OPTIONS`, требуют
  `Authorization: Bearer <token>`. Токен — 32 hex-символа, его можно
  перегенерировать в настройках.
- **HTTP без шифрования.** Используйте доверенную домашнюю сеть или VPN. Не
  открывайте порт `27123` в интернет.
- **Токен в открытом виде.** Он хранится в `data.json` плагина; любой, у кого есть
  доступ к папке vault, может его прочитать.
- **Безопасность путей.** Сервер отклоняет абсолютные пути, `..` и всё внутри
  `.obsidian` и исключённых папок.

## Совместимость и ограничения

- `isDesktopOnly` = `false`: плагин ставится и работает на телефоне как клиент.
  Node-модули (`http`, `os`) загружаются лениво только в desktop-ветке; если их
  нет, клиент продолжает работать.
- Синхронизация запускается вручную. Фонового демона и синхронизации по таймеру
  нет.
- Лимит файла по умолчанию — 50 МБ; меняется в настройках. На обоих устройствах
  должен быть одинаковым.
- Конфликты не сливаются автоматически: вы выбираете версию.
- Tombstone-записи хранятся бессрочно; очистка — вручную и необратимо.
- Исключённые папки должны совпадать на обеих сторонах.

## Разработка

```bash
npm install
npm run dev      # watch
npm run build    # typecheck + production bundle
npm run typecheck
```

Сборка даёт единый `main.js` (CJS). `obsidian`, `electron` и `@codemirror/*` —
внешние; `qrcode` и `diff` входят в бандл.
